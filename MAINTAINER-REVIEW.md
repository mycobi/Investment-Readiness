# Maintainer review record

Copy into a maintainer comment on each PR.

- PR and reviewed head commit:
- Reviewer:
- Classification: editorial / material / breaking
- Issue and RFC:
- Each contributor and acceptance link:
- CLA version and permanent link:
- Entity authorization or private agreement reference, if applicable:

## Required checks

- [ ] All original contributors are identified, including incorporated issue text.
- [ ] Each contributor has a verified separate acceptance or a CLA Assistant record.
- [ ] Acceptance covers this version and submission; copied issue authors and coauthors were checked.
- [ ] Employer rights and external-source permissions are resolved.
- [ ] No confidential evidence or proprietary implementation material is included.
- [ ] No paper or book manuscript is included.
- [ ] Claims, sources and interpretation changes were reviewed.
- [ ] Material changes have an accepted RFC; breaking changes have migration guidance.
- [ ] Credit and release notes are prepared.
- [ ] An authorized reviewer other than the PR author approved this revision.

Decision: accept / request changes / defer / reject

Rationale:

Do not merge with unresolved requirements. Explain any not-applicable item. A label or PR-author checklist is not a substitute. Recheck after substantive changes. Legal terms and license scope also require steward approval.
