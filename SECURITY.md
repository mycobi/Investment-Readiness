# Security policy

## Reporting a vulnerability or confidential concern

Email support@mycobi.com. Use this address for security vulnerabilities in this repository, suspected exposure of confidential material, and other concerns that should stay private.

Do not post sensitive information in public issues, pull requests, or discussions. That includes vulnerability details, credentials, private company records, and personal data.

Include enough for a maintainer to locate the problem: the affected file or area, what you observed, and how to reproduce it when that can be done without sharing confidential data.

## What happens next

Maintainers review private reports and reply by email. A public issue or pull request may follow only after sensitive detail has been removed.

Questions about the public specification belong in the issue forms or [Discussions](https://github.com/mycobi/Investment-Readiness/discussions). This policy does not disclose private scoring rules or product internals.

Conduct reports use the same address. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
