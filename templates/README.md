# Practitioner kit

Use this kit to review the public methodology without reconstructing private scoring.

1. Read the [practitioner guide](practitioner-guide.md).
2. Follow the [completed illustrative walkthrough](illustrative-walkthrough.md).
3. Copy the [field worksheet](field-review-worksheet.md).
4. Summarize results in the [findings report](findings-report.md).
5. Use the [case record](case-study-record.md) to document an authorized field case.

The walkthrough is hypothetical, not evidence from a real company. Templates are fillable Markdown documents. No tool here produces an official IRS. Keep confidential records outside public submissions.
